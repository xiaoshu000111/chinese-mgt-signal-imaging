# 03 如何把一维信号转成图像

三种方法都把长度 `T` 的一维序列 `X = (X_1, ..., X_T)` 映射成 `T×T` 的二维矩阵，动机是把「逐 token 的时序关系」显式暴露成 CNN 能学习的**局部纹理 + 全局结构**。

## 1. Gramian Angular Field（GAF）

先把 `X` 线性缩放到 `[-1,1]`，记 `φ_i = arccos(X_i) ∈ [0, π]`。

- **GASF（Summation）**：`GASF[i][j] = cos(φ_i + φ_j) = X_i X_j - √(1-X_i²)√(1-X_j²)`
- **GADF（Difference）**：`GADF[i][j] = sin(φ_i - φ_j) = √(1-X_i²) X_j - X_i √(1-X_j²)`

**特点**：对角线保留原始信号值（`GASF[i][i] = 2X_i² - 1`），主对角线附近是短程时序关系，远离对角线的区域是长程关系。适合捕捉平滑信号（logp、entropy）的「趋势 + 相关性」。

## 2. Markov Transition Field（MTF）

把信号按**分位数**分成 `Q` 个 bin，记每个时刻的 bin 索引 `q_t ∈ {1..Q}`。先统计一阶转移矩阵：

```
W[i][j] = P(q_{t+1} = j | q_t = i)    # 按 (q_t, q_{t+1}) 相邻对计数并归一化
```

再把每个 `(t1, t2)` 网格点填成 `W[q_{t1}][q_{t2}]`（常用沿时间轴展开成 `T×T`）。

**特点**：刻画信号的**马尔可夫转移结构**——注意它不做数值大小直接比较，而是「状态区间之间的跳转频率」。
- 对 `rank` 这条偏离散、语义上天然有「分档」含义的通道尤其合适（机器文本的 rank 也许更少跨越区间）。
- 若信号里出现同一 bin 内频繁抖动，会把转移矩阵对角线占据想成噪声，需合理设置 `Q`（文本短时 Q 要小）。

## 3. Recurrence Plot（递归图）

设定阈值 `ε`，二值化：

```
R[i][j] = 1  if |X_i - X_j| ≤ ε,  else 0
```

**特点**：只保留「值相近」的成对时刻，是所有三种里最稀疏、最结构化的表示。对「人工写作中词序/用词跳变导致信号大幅摆动」这类现象，递归图会把摆动画成明显的块状/对角断裂。`ε` 用距离分布的百分位数（如 20%）自适应确定。

## 4. 通道与 RGB 拼装策略（用于消融）

| 实验配置 | 做法 | 目的 |
|----------|------|------|
| 单通道 | 选一条信号 → 一种转图 → 得到 `(T,T,1)` 输入 CNN | 基准，锁定最有区分度的通道×方法 |
| 方法对比 | 同一条信号换 GASF/GADF/MTF/RP | 回答「哪种图最有效」 |
| 三通道 RGB | 把三条不同信号（或同一信号三种方法）拼成 `(T,T,3)` | 多信号融合，作为进阶模型 |

**首版建议**：先用 `logp` 做 GASF，跑通全链路拿到 baseline；再在同一框架下把「信号通道 × 转图方法」做成消融表，这正是中期答辩里最有区分度的贡献之一。

## 5. 实现注意

- 所有转图前都把信号缩放到方法所需区间（GAF 到 `[-1,1]`；MTF 看分箱；RP 看原始值域）。
- 图像统一存 `uint8`（0–255）PNG，训练时归一化到 `[0,1]`；避免用 `float32` 直接进 CNN 造成的数值不一致。
- `T` 固定后图像尺寸固定，CNN 输入尺寸写死在 `config.py`，不要在不同实验中漂移。
