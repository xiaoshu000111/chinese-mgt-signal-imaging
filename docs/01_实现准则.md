# 01 具体实现准则

本文档锁定整条管线「能做对、能复现、能答辩」的约束。写代码前先读这几条。

## 1. 信号提取的确定性

信号（token 概率序列）是整条路线的地基，必须保证**同一条文本任何时候跑出来都是同一条信号**。

1. 因果 LM 用 `model.generate=False` 只前向推一次，取 `logits` 得到整句的条件分布，不要用 `generate` 采样。
2. 固定 `torch.manual_seed` / `np.random.seed`，并设置 `model.eval()` 关闭 dropout。概率值受 float 精度影响，但排名与相对形状稳定。
3. tokenizer 一次实例化、全程复用；`add_special_tokens` 与截断策略写死在 `config.py`。
4. 信号算完立即落盘为 `.npz`（按 `sample_id` 命名），训练阶段只读缓存不重算。这样换基础模型、改转图方法都不需要重跑最慢的提取步骤。

## 2. 缩放与归一化要"跨样本一致"

GAF 靠 `arccos` 要求信号落在 `[-1,1]`，缩放方式会直接改变图像纹理。

- **推荐**：`logp / rank_norm / top_prob / entropy` 不用全局 min-max（会被单条样本的极端值主导），而用**全数据集分位数**做线性映射到 `[-1,1]`（超参存进 `.npz` 的元信息，测试集复用训练集的映射）。
- **避免**：逐样本 `min-max`，它会让短文本和高方差的样本产生不可比的图像。
- `rank` 通道直接 `rank / vocab_size` 天然落在 `[0,1]`，再线性压到 `[-1,1]`。

## 3. 人机共享完全相同的预处理

训练/验证/测试必须走**同一条 data pipeline**：同样的 tokenizer、同样的 T、同样的缩放映射、同样的转图参数。任何只在训练侧做的后处理（如增强）都要显式声明，不能悄悄进入测试。

## 4. 转图参数的可复现

- GAF：`(L, L)` 图像，`L = T`（信号长度固定后图像尺寸自然固定）。
- MTF：分箱数 `n_bins`（默认 8）固定；分箱用**分位数分箱**而非等宽分箱，避免长尾污染。
- 递归图：阈值 `eps` 用「按点距离分布的百分位数（如 20%）」确定，比绝对阈值更稳健。

## 5. 训练期与推理期的长度策略分离

- **训练期**：全部统一到固定 `T`（截断 + 边缘反射补齐），保证 batch 内尺寸一致。
- **推理期**：长文本用滑窗（窗长 `T`、步长 `T/2`）生成多张图，预测取 logits 平均；短文本补齐到 `T`。这样既统一输入又不丢长文信息。

## 6. 选型建议

| 组件 | 默认 | 说明与备选 |
|------|------|-----------|
| 基础 LM | `Qwen/Qwen2.5-0.5B` | 中文分词语义好、显存小（约 1GB）；可用 `Qwen2.5-0.5B-Instruct` |
| 信号通道 | `logp/rank/rank_norm/entropy/top_prob` | 最少保留 `logp + rank`，其余进消融 |
| 转图 | GASF（首选）| 单通道起步，之后做 GADF/MTF/RP 消融 |
| 分类器 | ResNet 风格小 CNN | 图像尺寸小，不必用大 ImageNet 骨干 |
| 优化器 | AdamW + cosine | 二分类 BCELoss / CE |

## 7. 中间产物与目录约定

- 信号：`data/processed/signals/{split}/{sample_id}.npz`
- 图像：`data/processed/images/{signal}_{method}/{split}/{sample_id}.png`
- 清单：`data/splits/{split}.csv`，列 `sample_id, text_index, label, model, source, signal_path, image_path`

训练、评估一律读 CSV 清单，不直接扫磁盘，保证同一份数据被同一种方式消费。
