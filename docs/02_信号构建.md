# 02 如何构建一维信号

## 直觉

给定一篇文本 `x = (x_1, ..., x_T)`，因果语言模型能算出每个 token 在**给定上文**时的预测分布：

```
P(x_t | x_1, ..., x_{t-1})
```

一个 token 若在机器看来「非常可预测」（机器生成文本往往更符合 LM 自己学到的统计规律，或与生成模型同族时更顺滑），其概率高、排名靠前、熵低；人工写作常出现让 LM 意外的用词、句式和跳跃。把这种「逐 token 的意外程度」画成一条随 token 变化的曲线，就是我们要的一维信号。

## 五条通道及公式

设 `x_t` 对应的分布为 `p_t = softmax(logits_t) ∈ R^V`（`V` 为词表大小），`p_t(j)` 中对应真实 token 的概率记为 `p_t(x_t)`。

| 通道 | 公式 | 含义 | 人机差异假设 |
|------|------|------|--------------|
| `logp` | `log p_t(x_t)` | token 的对数似然 | 机器文本整体 logp 更高、曲线更平滑 |
| `rank` | `#{j : p_t(j) > p_t(x_t)} + 1` | 真实 token 在分布中的排名 | 机器文本排名靠前，人工常靠后 |
| `rank_norm` | `rank_t / V` | 归一化排名 ∈ [0,1] | 消除词表规模影响 |
| `entropy` | `-Σ p_t(j) log p_t(j)` | 模型对下一个词的不确定性 | 人工文本熵更高、抖动更大 |
| `top_prob` | `max_j p_t(j)` | 分布峰值概率 | 机器文本峰值更集中 |

每条通道都是长度 `T` 的一维时间序列，合起来构成 `[5, T]` 的多通道信号。除上述 5 条外，可选进阶通道（成本较高，作扩展）：
- **扰动一致性**（DetectGPT 思路）：把 token 用近义词替换后看 logp 是否整体下降；
- **相邻差分** `Δlogp`、`Δentropy`：突出曲线的一阶变化，接近「曲率」信号。

## 提取实现要点

1. 用因果 LM 单次前向取 `logits`，`log-softmax` 后按真实 token id 取 `logp_t`。
2. `rank` 用向量化 `(p_t > p_t[x_t]).sum()` 计算，避免逐 token 排序。
3. 首 token 无上文，`logits_0` 对应的分布噪声大，可考虑丢弃首位置或单独平滑。
4. 全部分布只算一次，五条通道同源，保证后续消融公平（换通道不换信号来源）。

## 信号质量自查

- 画 `logp` 沿 token 的曲线，人工样本应出现更明显的下探（意外词），机器样本更平缓。
- 画人类/机器两条样本的 `entropy` 直方图，若几乎重合，说明基础 LM 选型不当（比如用英文 GPT-2 分中文），需换中文基础模型。
- 计算单通道的类间 KS 统计量做快速筛选：`rank_norm` 和 `logp` 通常分离度最高，可作为首版只用两通道的佐证。
